**Read** tools are always available. **Change** tools are listed only when the server is started with `visiconvert mcp --allow-changes`. No tool accepts Twilio credentials.

## `get_status`

**Read.** Server health, workspace, Twilio connection (including the webhook URLs to set on each Twilio number) and suggested next steps. Call this first.

No arguments.

## `list_numbers`

**Read.** Tracking numbers in this workspace with their source, campaign and forwarding destination.

No arguments.

## `list_twilio_numbers`

**Read.** Numbers in the connected Twilio account that are not tracked yet, so they can be assigned to a campaign.

No arguments.

## `list_leads`

**Read.** Leads (calls and other inquiries), newest first.

| Argument | Type | Required | Description |
|---|---|---|---|
| `include_demo` | boolean | No | Default: `false`. |
| `limit` | integer | No | Default: `50`. |
| `qualification` | `unreviewed`, `qualified`, `unqualified`, `spam` | No |  |
| `since` | string | No | 7d, 24h, 30m, or a date like 2026-10-01. |
| `source` | string | No |  |

## `get_lead_outcomes`

**Read.** Bookings and cancellations recorded on a lead.

| `lead_id` | string | Yes | Lead ID, or a unique prefix of at least 6 characters. |

## `source_report`

**Read.** Leads, qualified leads, bookings and booked revenue by marketing source.

No arguments.

## `add_tracking_number`

**Change.** Track a number already in the connected Twilio account for one source and campaign, forwarding calls to the business line. Afterwards the number's webhooks must be set in the Twilio console; the result says how.

| Argument | Type | Required | Description |
|---|---|---|---|
| `campaign` | string | Yes |  |
| `forward_to` | string | Yes | The business line calls ring through to. |
| `label` | string | No | Defaults to the campaign. |
| `phone_number` | string | Yes | The Twilio number to track, e.g. +15125550142. |
| `source` | string | Yes | Marketing source, e.g. Google Ads or Yard signs. |

**Change.** Record a booked job (with its value in USD) or cancel one. The reference, such as a job or invoice number, identifies the booking; reusing it revises that booking.

## Prompt: `set_up_call_tracking`

Walks an agent through setup:

1. Call get_status. If Twilio is not connected, stop and ask the person to connect it in the workspace UI. Scoped API keys cannot change provider credentials. Self-hosted operators using a legacy operator key can also run `visiconvert connect twilio --account-sid AC… --token-stdin` themselves. Never ask them to paste credentials into this conversation.
2. Ask which marketing sources and campaigns they want to track (for example Google Ads, Facebook, yard signs, the van), and which business line calls should ring through to.
3. Call list_twilio_numbers. Propose one untracked number per campaign and confirm the plan with the person. If there are not enough numbers, tell them how many more to buy in Twilio; buying is not available from these tools yet.
4. For each confirmed pair, call add_tracking_number.
5. Give the person the voice URL and status URL from the results, and the exact Twilio console steps for each number. These have to be set by hand for now.
6. Ask them to call one tracking number from their own phone, then call list_leads with since 15m and confirm the call arrived with the right source.
7. Summarise what is tracked, and anything left to do.
